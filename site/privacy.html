Lulltab

Privacy policy

Last updated September 23, 2026

The short version

Your tabs never leave your browser. Lulltab doesn’t sell or share any data, and there’s no account. Its only network request is an optional, anonymous daily ping, described below, that you can turn off in settings.

Anonymous usage stats

Once a day, Lulltab sends a small ping to analytics.n3el.dev, a server run by Lulltab’s developer, to count active installs. It contains:

  • a random install ID, created when Lulltab first runs and not linked to you or your account;
  • the Lulltab version, your Chrome version, and your CPU type (for example arm64).

It never includes your tabs, addresses, titles, settings, or anything else you do in the browser. No cookies are used. The server derives a country from the request and doesn’t store IP addresses. When you uninstall Lulltab, the browser opens a page on the same server that counts the uninstall and then forwards you to this site.

To turn it off, open Lulltab’s settings and uncheck Share anonymous usage stats. Lulltab then sends nothing, and uninstalls aren’t counted.

What stays on your device

  • Your settings — the idle timeout, the sites you keep awake, and switches like “Keep pinned tabs” — are saved in chrome.storage.local.
  • When each tab was last used is kept in chrome.storage.session, which the browser clears when it closes.
  • A random install ID and the date of the last usage ping are saved in chrome.storage.local.
  • If you turn on Debug mode, a short event log is saved in chrome.storage.local. It only leaves your device if you click Copy report and paste it somewhere yourself.

What Lulltab reads

  • Tab titles, addresses, and states (pinned, playing audio, sleeping), so it can decide which tabs to sleep and show them in the popup.
  • How much memory each tab uses, for the Memory view. When the browser doesn’t report memory per process, Lulltab reads the page’s JavaScript memory size. It doesn’t read page content.

None of this is sent anywhere, including in the usage ping.

This website

lulltab.n3el.dev uses the same cookieless counter from analytics.n3el.dev. It records the page path, the referring site, your country, and coarse browser and device type. It sets no cookies and stores no IP addresses, and visits can’t be linked across days.

Changes

If this policy changes, the new version will be posted on this page with a new date. The source code is public on GitHub, so you can check what the extension does.
